# Arivom - standalone website

Static HTML/CSS/JS package prepared for GitHub and Cloudflare Pages.

## Files
- `index.html` - main page
- `css/style.css` - responsive styling
- `js/script.js` - mobile menu and form message
- `assets/hero.jpg` - supplied hero artwork

## Cloudflare Pages
Push this folder to a GitHub repository, then create a Cloudflare Pages project from that repository. This site has no build step: deploy the repository root as static files.

## Important
The interest form is intentionally front-end only. It does not transmit or store personal data until you connect an appropriate form/backend service and update `js/script.js`.
